# Title tags (Google Search Central style guidance — summarized for offline RAG)

Title tags are a primary on-page relevance signal and the default SERP headline.

## Best practices
- Keep titles unique per URL.
- Aim for roughly 15–60 characters so the title is unlikely to truncate on desktop SERPs.
- Place the primary keyword near the front without keyword stuffing.
- Match user intent for the page type (product, article, category, homepage).
- Avoid boilerplate reuse of the same brand-only title across many URLs.

## Common issues
- Missing `<title>` elements.
- Duplicate titles across pages (often from a shared template with no page-specific slot).
- Excessively long titles that truncate mid-phrase.
