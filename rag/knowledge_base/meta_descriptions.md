# Meta descriptions

Meta descriptions do not directly affect rankings but strongly influence click-through rate.

## Best practices
- Write a unique description per page (about 50–160 characters).
- Accurately summarize the page; include a soft call to action when natural.
- Do not duplicate descriptions site-wide from the layout template.

## Common issues
- Missing meta description (search engines auto-generate snippets, often poorly).
- Descriptions that are too short to be compelling or too long and truncated.
